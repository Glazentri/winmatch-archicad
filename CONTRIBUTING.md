# Contributing

Please describe the workflow, browser/Archicad version and expected behaviour. Use a fictional example or sanitised workbook rather than uploading clients' models or schedules. PRs should include a regression test and preserve the original WinMatch project v1 format. Keep file conversion local, retain workbook identity protections, and never infer manufacturing dimensions or write into unreviewed properties. Run `node --test tests/exchange.test.cjs` before submitting.
