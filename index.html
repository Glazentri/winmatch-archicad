Setup & limitations

Not yet tested inside Archicad. Our template is for importing into WinMatch, not a native Archicad property workbook.

1. Prepare your schedule

Export windows and doors with ID, element GUID if available, type (Window / Door), height, width, quantity, storey and room. Export one unique element per row for a return workflow. Do not merge identical elements. Select the actual units below; dimensions and panel configurations need review in WinMatch.

For return: in Archicad use File → Interoperability → Classifications and Properties → Export Property Values from Schedule. Include the editable text properties you want to update. Keep that exact original XLSX file.

2. Review and return

Download the project JSON, then import it into WinMatch using the normal project import. That workflow asks before replacing an occupied project. Review configurations and specifications, save the project JSON, then load it below.

Return changes only mapped text-property cells in your original workbook. In Archicad, use Import Property Values into Elements and inspect its preview before applying. Built-in dimensions, geometry and library parameters are not changed.

Map your columns below. Mixed window/door schedules must map the type column. Hidden columns are listed too. Formula cells must be exported as plain values.

Return reviewed text properties

Keep the original XLSX selected above. CSV and TSV imports can create a WinMatch project, but cannot produce a native property workbook. Load the reviewed project JSON exported from WinMatch. The standalone edition does not read the live workspace.

Choose the original workbook columns for custom text properties only. Leave fields unmapped to keep their cells unchanged. Blank or TBC values are skipped. Identifiers and mapped source dimensions cannot be overwritten.

Before you use it

  • Only Element Properties supported by Archicad's spreadsheet importer can return. Glazing and frame colours can return only if your model has matching editable text properties.
  • Keep the exact original workbook, source worksheet, headers and element identifiers. The tool checks file identity, source rows and unique source IDs before preparing changes.
  • Grouped rows, ambiguous IDs, formulas in mapped cells, protected source worksheets and mismatched source files stop the return. Unmatched new WinMatch rows are skipped and reported.
  • Workbook values, sheets, hidden rows/columns, styles and identifiers are retained where supported by the spreadsheet library. Special Excel features, macros and signatures are unsupported. Use a copy of the model and verify the return workbook inside Archicad.
  • This is file exchange, not an Archicad add-on or live sync. No model geometry, handing or panel layout is inferred.
