# Examples

- `schedule.csv`: two fictional window/door rows; import with millimetres, worksheet Schedule, header row 1.
- `schedule.xlsx`: same fictional rows in a workbook, with an extra sheet to test preservation. **Not a native Archicad property export.** It demonstrates how the reviewed text-only workflow works in the app, not compatibility with Archicad's import format.
- To use real models, create and retain the property workbook exported by Archicad itself and verify the import preview in Archicad.
